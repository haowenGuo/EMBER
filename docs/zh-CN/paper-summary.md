# 论文脉络摘要

本文围绕“多轮对抗性交互场景下的大模型涌现式偏见评估与缓解”展开，核心贡献可以整理为四层。

## 1. EMBER：动态评估框架

论文首先指出静态偏见评估难以覆盖真实交互场景中的风险。大模型在单轮回答中可能表现中立，但在多轮对抗、长上下文累积和群体压力下，可能逐步出现更强的偏见表达。EMBER 因此构建了多智能体对抗交互框架，通过目标模型与对抗智能体的连续辩论，观察偏见随轮次演化的趋势。

## 2. EMBER-Agent：推理期动态缓偏

在发现传统提示词缓偏容易随轮次衰减后，论文提出 EMBER-Agent。它将 ReAct 思路改造为偏见缓解任务中的“思考-反思-观察-执行”闭环，使模型在输出最终回答前进行自检和重写。该方法不需要训练新模型，但会增加推理阶段的 token 与延迟开销。

## 3. 风险感知参数高效缓偏

为降低 EMBER-Agent 多次自检带来的推理成本，论文进一步提出风险感知参数高效缓偏算法。该算法在冻结底座模型的基础上引入风险头与低秩适配器，通过监督微调和强化学习调整模型生成倾向，使模型在推理时更少依赖外部反思调用。

## 4. EMBER-Harness：工程化部署控制层

论文第 4 章进一步讨论如何把 EMBER-Agent 放入真实 agent 系统。核心问题是：如果只检查最终输出，风险发现过晚；如果每次模型调用都检查，成本过高。EMBER-Harness 因此提出阶段门控策略，在输入解析、记忆读取、检索增强、任务规划、工具结果、草稿生成和最终输出等语义阶段边界进行检查。

该机制包含：

- 阶段拆分
- 阶段快照
- EMBER Gate 风险评审
- 最近安全快照回退
- 审计日志

## 5. 实验结论

论文实验显示，多轮对抗交互能够诱发并放大大模型偏见；EMBER-Agent 相比传统提示词缓偏具有更稳定的动态缓解效果；风险感知参数高效方法在部分设置下进一步降低偏见得分并减少推理期额外开销；EMBER-Harness 则在工程层面提供了一种介于最终输出自检和逐调用自检之间的安全-成本折中方案。
